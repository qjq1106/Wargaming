# Wargaming

一个轻量的中国历史人物战争自动模拟小游戏。

## 项目定位

- 玩家负责组局：选择参战势力、人物组合和少量规则参数。
- 系统负责开战：各势力在中国地图上自动扩张、交战和吞并。
- 玩家负责观战：以上帝视角控制开始、暂停、继续、调速、重开和退出。

## 第一版目标

- 做出一个简单、可反复游玩的单机小游戏。
- 战争过程热闹直观，地图上能清晰看到势力推进和消亡。
- 结果不可预知，避免玩家一开局就知道谁会赢。
- 底层支持单人、双人、多人阵容，方便后续扩展历史人物组合。
